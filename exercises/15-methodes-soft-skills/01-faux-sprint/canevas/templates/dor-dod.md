# Definition of Ready / Definition of Done

## Definition of Ready (DoR)

Un ticket peut entrer en sprint si :

- [ ] Titre actionnable
- [ ] Contexte (le **pourquoi**) écrit dans la description
- [ ] Critères d'acceptation testables
- [ ] Maquette UI / contrat API si pertinent
- [ ] Edge cases listés
- [ ] Out of scope explicite
- [ ] Estimation rough faite (T-shirt ou points)
- [ ] Pas de dépendance bloquante
- [ ] Compris et challengé par au moins un dev

## Definition of Done (DoD)

Un ticket est terminé quand :

- [ ] PR mergée sur `main`
- [ ] Tests automatisés passent
- [ ] Code review validée (au moins 1 approve)
- [ ] Documentation à jour (README, OpenAPI, ADR si pertinent)
- [ ] Déployé en staging et validé
- [ ] AC cochés par PO ou champion
- [ ] Métriques (perf, erreurs, accessibilité) inchangées ou améliorées

À adapter et afficher en haut de Linear / GitHub Project / Notion.
