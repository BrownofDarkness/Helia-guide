# Personas

## Persona principal — Marie

| Champ | Valeur |
|-------|--------|
| **Nom** | Marie Dupont, 42 ans |
| **Métier / contexte** | Médecin généraliste, vit à Lyon avec sa famille |
| **Objectifs** | Retrouver rapidement un livre dans sa collection ; savoir ce qu'elle a déjà lu ; récupérer ses livres prêtés |
| **Frustrations** | « Je rachète parfois un livre que j'avais déjà ! » ; livres prêtés et oubliés ; piles de livres impossibles à parcourir physiquement |
| **Compétences tech** | À l'aise avec navigateurs, smartphone, Word/Excel ; pas développeuse, pas de patience pour configurer |
| **Téléphone / desktop** | iPhone (priorité) + ordinateur familial occasionnel |
| **Phrase clé** | *« Je veux que ça marche tout seul, sans manuel »* |
