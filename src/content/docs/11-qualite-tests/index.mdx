> 🎯 **Objectif global** : produire un code lisible, testé, maintenable que d'autres pourront reprendre sans douleur.

<Aside type="note" title="Tests dans les axes précédents — où est la frontière">
Tu as déjà vu des tests dans les axes 7 (Vitest+Testing Library), 8 (pytest, Pest, Vitest+supertest) et 6.1 (premiers Vitest sans framework).

- **Axes 6-7-8** : tests **comme outil quotidien** — assert simple, golden path, 1-2 edge cases.
- **Axe 11 (ici)** : tests **comme discipline** — pyramide testing, TDD, mocks/stubs/fakes, contract testing, mutation testing, golden set, coverage significatif.

Si tu n'as jamais écrit un test, va d'abord faire 1.1 et 6.1 — reviens ici quand tu as 5–10 tests à ton actif.
</Aside>
