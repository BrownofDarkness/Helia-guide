## Pourquoi Helia ?

Helia est un guide d'apprentissage du développement web pensé pour la francophonie, gratuit et public. L'objectif : amener un débutant complet **de zéro à dev compétent** en évitant deux pièges classiques de l'apprentissage en autodidacte :

- **La fragmentation** : un tuto HTML par-ci, une vidéo React par-là, une formation Python ailleurs — au bout de 6 mois on connaît 50 trucs sans savoir comment ils s'assemblent.
- **L'abstraction sans pratique** : trop de cours expliquent les concepts sans jamais coder un projet réel de bout en bout.

Helia répond aux deux par un parcours **cohérent** (17 axes des fondations à la carrière) et **immersif** (5 personas fil-rouge qui construisent chacun un vrai projet à travers les axes).

## L'origine du nom

**Helia** est un mot **inventé** qui condense trois inspirations :

| Source | Apport |
|---|---|
| **Helix** (spirale) | L'apprentissage qui s'élève en spirale, on revient sur les mêmes notions à chaque tour avec plus de profondeur. |
| **Iris** (arc-en-ciel, messagère) | Les **5 fils narratifs** colorés — Marie, Hugo, Sami, Léa, Yanis — qui tissent le parcours. |
| **Sonorité africaine** | Une touche assumée de la **diaspora camerounaise** d'où vient l'auteur. Helia se prononce identique en FR et EN, sans accent, passe-partout international. |

Hélios en grec signifie aussi « soleil » — d'où le **soleil ambre** au centre du logo, autour duquel orbitent les 5 chevrons `>` colorés (un par persona).

## Ce qui rend Helia différent

- **Multi-langages backend** : 3 parcours (Node/TS, Python, PHP) au lieu d'imposer un seul écosystème.
- **32 pièges réels documentés** au format Symptôme · Cause · Fix · Leçon — les vrais bugs rencontrés pendant la construction du guide.
- **280 termes au glossaire** consultables au survol partout dans le contenu.
- **2026-frais** : React 19, Next.js 16, Vue 3.6, Astro 6, Postgres 17 — pas de tuto périmé.
- **Carrière transversale** : l'axe 17 est numéroté en dernier mais ses conseils sont actionnables dès l'axe 4 — construis ton portfolio pendant l'apprentissage, pas après.

## Qui est derrière

Helia est construit par une seule personne en open source. Pour proposer une amélioration, signaler une coquille ou suggérer un ajout, le canal préféré est **GitHub** (lien dans le footer).

## Crédits techniques

- **Astro 6** + **Starlight 0.38** pour le moteur statique et la documentation
- **Mermaid** pour les diagrammes
- **Pagefind** pour la recherche full-text
- **Inter** + **JetBrains Mono** pour la typographie
- Inspirations UI : Vercel Docs, Linear, Stripe Docs, Cal.com Docs, Astro Docs
