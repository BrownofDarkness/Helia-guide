> 🎯 **Objectif global** : livrer des expériences rapides, accessibles et internationalisables — au niveau exigé en 2026 (Core Web Vitals, EAA, WCAG 2.2 AA).

<Aside type="note" title="Perf et a11y dans les axes précédents — où est la frontière">
Tu as déjà vu :
- **Axe 5.1 (HTML sémantique)** : balises `<header>` `<nav>` `<main>`, `alt`, `<label>` — **socle** a11y.
- **Axe 5.3 (Accessibilité)** : WCAG niveau AA, contrastes, focus visible, navigation clavier — **niveau confirmé** a11y.
- **Axe 5.2 (CSS moderne)** : `width`/`height` sur images, `prefers-reduced-motion` — **socle** perf.
- **Axe 7 (Frameworks)** : Server Components, code splitting, lazy loading — **niveau confirmé** perf via outils.

L'axe 13 (ici) ajoute la **discipline avancée** : Core Web Vitals (LCP/INP/CLS), Lighthouse CI, RUM, profilage backend, EAA 2025, i18n RTL, propriétés logiques CSS. **C'est l'axe pour passer du « ça marche » au « ça respecte les standards 2026 »**.
</Aside>
