**Refonte Lighthouse** — partir d'une page volontairement catastrophique (que des `<div>`, `outline: none`, contraste #aaa sur blanc, formulaire sans `<label>`…) et la réécrire pour atteindre **≥ 95 sur les 4 axes Lighthouse**. Mesure automatisée via Chrome headless + Lighthouse CI.
