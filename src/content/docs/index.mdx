## Pourquoi ce guide ?

La plupart des ressources d'apprentissage du dev web sont **fragmentées** : un tuto HTML ici, une vidéo React là, une formation Python ailleurs. Au bout de 6 mois, tu sais 50 trucs sans savoir comment ils s'assemblent.

**Ce guide rassemble tout en un parcours cohérent** : du « comment fonctionne un ordinateur » jusqu'au déploiement en production, en passant par l'analyse, la sécurité, l'accessibilité, le DevOps et la carrière.

Trois différences avec ce que tu as déjà vu :

| Différence | Ce que ça change |
|------------|------------------|
| **Un personnage qui code avec toi** | Tu vois pourquoi tu apprends `Flexbox` aujourd'hui — pour aligner les cartes produits de Lina |
| **Multi-langages backend** | Trois parcours — Node/TS (Hono), Python (Django/Flask/FastAPI), PHP (Laravel/Symfony) — choisis le tien |
| **Tout 2026** | React 19, Next.js 16, Vue 3.6, Svelte 5, Astro 6, Postgres 17, Hono, Drizzle, Better Auth — pas de tuto périmé |

## À qui s'adresse ce guide ?

- **Débutants complets** — tu n'as jamais codé, ce guide est ton point d'entrée. Suis-le linéairement.
- **Devs en reconversion** — tu as une base technique (autre métier IT, formation courte) — pioche les axes qui te manquent.
- **Juniors** — combler les lacunes typiques : analyse, sécurité, DevOps, soft skills, carrière.
- **Devs confirmés** — référence sur les sujets 2026 (IA appliquée, edge, RGPD, accessibilité).
