## Projet de l'axe

**Mini-curl en Node.js.**
Un client HTTP en ligne de commande qui imite `curl -v` : suit les redirections, affiche les en-têtes envoyés et reçus, supporte POST avec corps, mesure les temps DNS / TCP / TLS / TTFB.
