## Projet de l'axe

**Tasky Pro — SaaS minimal en un week-end** — un SaaS complet déployé en < 16 h de travail effectif. Next.js 16 + Clerk (auth) + Stripe (paiement signed webhooks) + Supabase (DB + RLS) + Resend (email transactionnel), déployé sur Vercel. **Coût d'un MVP : 0 €/mois** jusqu'à atteindre certains seuils.
