## Projet de l'axe

**Un mini-projet de spé** dans la spécialisation choisie :

- **Mobile** : PWA installable + push notifications + offline.
- **Temps réel** : éditeur collaboratif type Notion (Yjs).
- **3D** : configurateur 3D produit (Three.js + R3F).
- **IA** : assistant RAG sur ta propre doc (l'exercice fourni).
- **Edge / WASM** : API mondiale Cloudflare Workers + traitement image WASM.
- **Web3** : SIWE + dashboard de tokens lus via The Graph.

<Aside type="tip" title="🎯 Tu peux attaquer ce projet dès la fin de 16.4">
Le projet **Assistant RAG** s'appuie uniquement sur **16.4 (IA appliquée)**. Les sous-axes 16.5 (Edge/WASM) et 16.6 (Web3) sont des spécialisations **alternatives** qui ne servent pas à ce projet précis.

Deux trajectoires valides :
- **Pratique à chaud** : tu lis 16.4 puis attaques le RAG — la spé IA est ta voie principale.
- **Tour d'horizon d'abord** : tu parcours 16.5 et 16.6 pour décider si une autre spé t'attire davantage avant de t'investir 8-12 h.
</Aside>
